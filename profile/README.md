# Good Stories

**A Media Tech Lab for storytellers and their AI agents.**

Good Stories LLC builds narrative intelligence, agent-ready tools, and practical production workflows for writers, media teams, and entertainment companies. Our work is designed to be specific, reviewable, and useful in a real creative process.

[Visit the lab](https://goodstories.world) · [Explore the API](https://goodstories.world/api) · [Read the API docs](https://api.goodstories.world/docs)

## What we're building

- **Narrative API** — Search story patterns and generate structured summaries, rewrites, extractions, audits, and content workflows.
- **Story Lens** — Put a premise through a transparent, deterministic narrative analysis before spending a model call.
- **Agent skills** — Reusable workflows that help AI agents analyze stories and prepare production-ready briefs.
- **Agent-payments research** — Standards-aligned payment and receipt design. API-key access is live; public pay-per-call access is not yet available.

## Start here

- Create a free, verified API key from the [API page](https://goodstories.world/api).
- Install the Claude plugin from our public marketplace:

  ```text
  /plugin install good-stories --marketplace goodstoriesworld/goodstories-agent-skills
  ```

- Explore the [Good Stories agent skills](https://github.com/goodstoriesworld/goodstories-agent-skills).
